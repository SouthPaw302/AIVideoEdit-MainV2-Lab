# AIVideoEdit Reusable System
Everything here must be project-neutral and usable without opening an unrelated production branch.

Canonical directories: `fx_v2/`, `generative-engine/`, `painterly-motion/`, `memory-atmosphere/`, `depth-parallax-25d/`, `tools/`.

Reusable folders, IDs, presets, examples, and callable symbols are named after capabilities, never productions. Code that still depends on production-specific media/paths/story constants has not completed promotion.
