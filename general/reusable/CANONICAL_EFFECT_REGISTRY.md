# Historical Capability Catalog — Compatibility Pointer

This filename is retained for compatibility with older documentation. It is **not** the callable production authority and must not be used to import another production's art direction, story, characters, or media.

## Current authority
- Callable FX and gate status: `general/reusable/fx_v2/registry.json`
- Production capability discovery: `SYSTEM_INDEX.md`
- Media forms: `general/reusable/MEDIA_CAPABILITY_MATRIX.json`
- Capability ownership/promotion: `general/reusable/CAPABILITY_LINEAGE.md`

Historical project names are provenance only. A new production may reuse a neutral implementation, but historical visual/story direction is unavailable unless the current user explicitly authorizes it.
