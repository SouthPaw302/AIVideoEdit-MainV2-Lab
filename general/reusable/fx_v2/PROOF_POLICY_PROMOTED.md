# Promoted Effect Proof Policy

A promoted effect is not accepted because a historical project mentioned it. Acceptance requires a neutral callable name, a concrete implementation, deterministic execution on a synthetic reference plate, visible source delta, visible temporal delta, a committed verification record, and CI coverage. Historical labels remain aliases only.

The verifier intentionally proves implementation activity and temporal behavior. It does not claim semantic correctness for a specific shot; shot-level masks, anatomy protection, physical plausibility and creative QC remain mandatory production gates.
