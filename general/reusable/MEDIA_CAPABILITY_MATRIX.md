# Media Capability Matrix

Every production should deliberately choose the media forms that serve its story instead of defaulting to stills + zoom.

Available families: supplied/source footage; extracted frames; supplied images; generated stills/key art/support imagery; living paintings; layered composites/mattes; depth maps and 2.5D spatial shots; atmospheric/particle plates; audio-reactive procedural plates; loop media; authored transition media; actual NeRF/radiance-field media when trained/rendered; true 3DGS when real splat geometry exists; conventional finished video; analysis/QC media.

See `MEDIA_CAPABILITY_MATRIX.json` for machine-readable IDs and requirements.
