# Visual DNA — Island Memory Tapestry

**Authority:** current user direction only.

- Hand-painted, tactile, material-first imagery.
- Canvas weave/pigment tactility persists through every transformation.
- Ink, thread, water, stone, cloud and light transform into one another without reading as a digital slideshow.
- Internal material motion precedes camera motion.
- No identifiable faces in ancestral silhouettes.
- No modern objects, typography, flags, logos or literal country labels.
- No unprompted architecture, props or hallucinated elements.
- Camera moves only as declared per shot.
- Morphs preserve material lineage from outgoing to incoming scene.
- Opening palette: parchment/faded ink/oxidized blue/earth.
- Ocean: deep blue-green; village/fort: weathered ochre/grey/umber.
- Homeland: restrained luminous memory color.
- Silhouettes: charcoal within desaturated smoke/water.
- Final thread: condensed jewel-spectrum memory against near-black.
